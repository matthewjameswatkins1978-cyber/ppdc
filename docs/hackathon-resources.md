# PayPal hackathon resources

Last verified against the official PayPal AI Hackathon Devpost pages on 2026-10-06. Offers are not recorded as claimed until visible in the relevant account.

| Resource | Offer / quota | How to claim | Expiry / restrictions | PPDC plan |
|---|---|---|---|---|
| PayPal Developer | Free sandbox; create business and buyer sandbox accounts and a REST app | Sign in at developer.paypal.com, create sandbox accounts and app | Sandbox only; no real payments | Required; core integration |
| Channel3 | Claimed: 20,000 bonus API credits (`PAYPAL-HACKATHON-2026`); dashboard confirms 21,000 bonus credits remain (includes 1,000 initial balance) and 999/1,000 monthly credits remain after smoke test | Redeemed in signed-in dashboard; no card required | No promo expiry stated; top-up support via PayPal Discord | Planned for marketplace/product results; strong fit |
| Render | $50 credits | Claim through Devpost Render page credit portal, then verify account billing balance | Credit depletion is billable; do not create chargeable services until balance is visible | Candidate for hosting after verified credit; no deployment yet |
| Astropods | Free account advertised; hackathon-specific credit amount not stated | Sign up from Devpost Astropods page, inspect dashboard and usage/pricing | Do not run model until free credit and hard spending controls are confirmed | Evaluate only; use if free inference is clearly adequate |
| Parallel | No PayPal hackathon offer; its official pricing page currently advertises up to 5,000 free requests/month and up to $80 signup credit plus $5 monthly credit | Sign up at Parallel only if the user wants a second search provider; inspect the actual account grant before calling the API | Search API $0.001–$0.005 per 10 results; Extract API $0.001 per URL. Credits/allowance subject to current plan and account eligibility | Optional; Channel3 is the planned product-search source |
| APIMatic | One month of APIMatic Basic for entrants who used the PayPal Context Plugin; winning teams using it receive six months Business | Plugin installed from official PayPal Devpost guide into Codex, Cursor, and VS Code; subscription claim form is separate | Eligibility/terms on claim form; experimental preview plugin, not long-term supported; no runtime API credit | Use during implementation for PayPal API context; no runtime dependency |
| Postman | Free Postman plan and official PayPal Public API Workspace; no extra hackathon quota stated | Public workspace: https://www.postman.com/paypal/paypal-public-api-workspace/ | Do not export workspace secrets | Planned as developer test tooling |
| KERNEL | $50 credits | Claim through the Devpost KERNEL credit link | Expiry and billing behavior not stated on Devpost | Available, not yet required; no browser automation planned |
| AG Grid | Free 45-day trial license for AG Studio | Claim from the [AG Grid Devpost page](https://paypalaihackathon.devpost.com/details/aggrid) | Trial period stated; any later pricing/card requirement not stated | Not planned; PPDC is not an analytics dashboard |
| Bryntum | 45-day trial | Claim from the [Bryntum Devpost page](https://paypalaihackathon.devpost.com/details/bryntum) | Trial period stated; any later pricing/card requirement not stated | Not planned; no scheduling need |
| Elastic | 14-day free trial, with a self-serve 30-day extension form; Elasticsearch can also run locally for free | [Elastic Devpost instructions](https://paypalaihackathon.devpost.com/details/elastic) | No credit card statement found; do not provision hosted cluster until billing terms are checked | Not planned; Channel3 handles product discovery more directly |
| Zapier | New accounts get a 14-day Professional trial without a card, then automatically move to Free | [Zapier Devpost page](https://paypalaihackathon.devpost.com/details/zapier) | 14 days; automatic transfer to Free after trial | Not planned; no automation need for the MVP |

The hackathon rules require PayPal sandbox plus an AI tool of choice. Sponsor tools are optional. No offer is treated as applied based solely on the public offer page.
