# Infrastructure notes

- **PayPal:** Use the free sandbox. Secret Hatch is available locally but has no active capabilities, so the sandbox client ID and secret are in the ignored local `.env` as `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET` (aliases `paypal.client_id` and `paypal.client_secret`). OAuth, order creation, lookup, Sandbox Personal buyer approval, capture, and fresh `COMPLETED` read were verified. The configured return URL redirected to localhost and showed `ERR_CONNECTION_REFUSED` when the app was not running; the server-side flow still completed. Never use live credentials or real money for setup.
- **Hosting:** Render is an optional later deployment target. The signed-in Hobby workspace now shows the $50 Hackathon Participant credit applied, full balance remaining, valid until 2027-10-01; no card, services, or pending charges are present. The billing page says usage beyond included limits may be charged and credits apply to the next invoice. Keep building locally; estimate and review any service cost before deployment.
- **AI endpoint:** Astropods' $10 signup credit is applied; usage is $0, no payment method is on file, and the billing page shows a $5 alert and $20 hard stop. Its gateway charges platform credits (1 credit = $0.001), with example base compute of 2 credits plus model-dependent token costs. Exact gateway model options are not exposed in the account before deploying an agent. Do not use Astropods for PPDC's MVP unless a concrete agent-hosting need appears; a test would require creating an agent. BYO model-provider tokens are billed by that provider. Any AI provider is acceptable under the hackathon rules.
- **Runtime extraction:** Tesseract.js OCR runs on the server for JPEG/PNG/WebP screenshots (up to 8 MB), with assets cached under ignored `.cache/tesseract/`. Extraction uses a strict Zod schema, validates every quoted evidence reference against OCR, and keeps a deterministic local fallback. No local model runtime is installed. The existing Codex CLI returned schema-shaped output in a fictional-listing evaluation (26,491 account tokens). A second evaluation on a synthetic listing screenshot after local Tesseract OCR used 21,867 account tokens and inferred `item: guitar` without a supporting quote; the validator rejected it. Codex CLI is a hosted agent CLI, not selected as the app runtime. Parallel Responses performs live web research, so do not send private deal text through it. The Google Gemini Interactions adapter uses JSON Schema with no tools/search. It now reads the REST response's `steps[].content[]`; one live structured-extraction request passed schema and evidence-quote validation. A first request revealed that the REST API does not return the SDK convenience field `output_text`, then one follow-up validated successfully after the adapter fix. The key was available in the local process and is now stored in ignored project `.env`; its original source is unverified. As of 2026-10-07, Google lists free-tier pricing for `gemini-3.1-flash-lite`; its current API terms give UK unpaid usage the Paid Services data-handling terms, while restricting API clients offered to UK users to Paid Services. Therefore free-tier Gemini is suitable only for local development/testing; public UK deployment requires an eligible paid service or a different provider. Do not add billing or a card; leave the app on `rules`. Public search services continue to receive sanitized query objects only. [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [Gemini API terms](https://ai.google.dev/gemini-api/terms.md), [structured output](https://ai.google.dev/gemini-api/docs/structured-output).
- **Product search:** Channel3 is the planned primary source for retail product results and its PayPal promo has been redeemed. Parallel Search + Extract is a ready optional fallback, not a listed hackathon sponsor; the account has a visible $20 grant for 60 days and one search plus one extraction succeeded without adding a card. The account's current key is in ignored local `.env` as `PARALLEL_API_KEY`. Avoid scraping retailer pages as a substitute unless allowed by their terms.
- **APIMatic:** The PayPal Context Plugin gives coding agents API context and needs no APIMatic credentials according to the Devpost page. It is developer tooling, not a PPDC runtime dependency.
- **Postman:** Import `postman/PPDC-PayPal-Sandbox.postman_collection.json` into a local Postman workspace for OAuth, Orders create/capture, and order lookup. The collection has no secrets; keep credentials in a local, unshared Postman environment and never sync or export them.
- **KERNEL:** The $50 hackathon credit activation produced a success toast; account billing showed no payment method and a trial end date of 2026-11-15, but did not expose the exact remaining credit balance. Internet-capable browser automation is not a PPDC requirement, so leave KERNEL unused unless a genuine need appears.
