# Infrastructure notes

- **PayPal:** Use the free sandbox. Secret Hatch is unavailable in this shell, so the sandbox client ID and secret are in the ignored local `.env` as `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET` (aliases `paypal.client_id` and `paypal.client_secret`). OAuth, unpaid order creation, and lookup were verified; the GBP 1.00 setup order remains uncaptured. Never use live credentials or real money for setup.
- **Hosting:** Render is an optional later deployment target. The hackathon page advertises $50 in credits. Verify the account balance before creating a service; credit depletion is billable. The project can remain local while the MVP is built.
- **AI endpoint:** Astropods' $10 signup credit is applied; usage is $0, no payment method is on file, and the billing page shows a $5 alert and $20 hard stop. Its gateway charges platform credits (1 credit = $0.001), with example base compute of 2 credits plus model-dependent token costs. Exact gateway model options are not exposed in the account before deploying an agent. Do not use Astropods for PPDC's MVP unless a concrete agent-hosting need appears; a test would require creating an agent. BYO model-provider tokens are billed by that provider. Any AI provider is acceptable under the hackathon rules.
- **Product search:** Channel3 is the planned primary source for retail product results and its PayPal promo has been redeemed. Parallel Search + Extract is a ready optional fallback, not a listed hackathon sponsor; the account has a visible $20 grant for 60 days and one search plus one extraction succeeded without adding a card. The account's current key is in ignored local `.env` as `PARALLEL_API_KEY`. Avoid scraping retailer pages as a substitute unless allowed by their terms.
- **APIMatic:** The PayPal Context Plugin gives coding agents API context and needs no APIMatic credentials according to the Devpost page. It is developer tooling, not a PPDC runtime dependency.
- **Postman:** Import `postman/PPDC-PayPal-Sandbox.postman_collection.json` into a local Postman workspace for OAuth, Orders create/capture, and order lookup. The collection has no secrets; keep credentials in a local, unshared Postman environment and never sync or export them.
- **KERNEL:** The $50 hackathon credit activation produced a success toast; account billing showed no payment method and a trial end date of 2026-11-15, but did not expose the exact remaining credit balance. Internet-capable browser automation is not a PPDC requirement, so leave KERNEL unused unless a genuine need appears.
