# PPDC demo scenarios

Three synthetic 30–60 second walkthroughs informed by public UK marketplace patterns reviewed 7 October 2026. None recreates a listing or seller. No source URLs, ad copy, seller identifiers, images, contact details, or private data are included.

Prices are illustrative, not current valuations. Read each JSON's initial state and turns in order. Expected demonstrations are teaching goals, not guaranteed app output. These assets are separate from production code and are not wired into the UI. The current assessor does not independently value items, verify seller claims, or infer seller intent.

Goods & Services does not guarantee protection or reimbursement; check current terms and transaction eligibility. Friends & Family is not intended for purchases. Risk signals warrant questions or a pause, not an accusation. No paid services, PayPal calls, or live checkout.
